# Global Pi Instructions

## Primary Stack
- Craft CMS 5 (PHP 8.2+) - main CMS platform
- Next.js (TypeScript) - frontend framework
- Astro - static site generator
- Tailwind CSS - styling
- Vite - build tool

## Project Context Loading
- For Craft CMS projects: Auto-load craftcms, craft-php-guidelines, craft-twig-guidelines, ddev skills
- For frontend work: Load craft-site and craft-twig-guidelines
- For PHP development: Load craft-php-guidelines
- For local development: Load ddev

## Workflow Preferences
- Always check for existing code patterns before suggesting changes
- Prefer Craft-native solutions over custom code when possible
- Use best practices from official Craft documentation
- For templates: Follow craft-twig-guidelines conventions
- For PHP: Follow craft-php-guidelines conventions

## When in Doubt
- If no project-specific AGENTS.md exists, ask about the stack before assuming
- If uncertain about a framework or library, ask for clarification
